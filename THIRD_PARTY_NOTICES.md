# Third-party code

The `baselines/gncdm_poly` implementation was adapted from the public
[Generative Cognitive Diagnosis](https://github.com/CSLiJT/Generative-CD)
repository by Jiatong Li, Qi Liu, and Mengxiao Zhu.

The upstream repository does not currently contain a license file. This
repository therefore does not grant additional rights to that upstream code.
Confirm redistribution permission with the upstream authors before publishing
the adapted G-NCDM files. The original attribution notices are preserved in
the source files.

The `baselines/ncdm_poly` implementation is an experimental continuous-score
adaptation of Neural Cognitive Diagnosis used in the accompanying paper.
